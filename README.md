# AI-Powered SmartBudget Manager 🧠💰

AI SmartBudget is a serverless personal finance and wealth management dashboard that combines modern budgeting methodologies with real-time market data integration and automated AI-driven financial insights. 

It is designed to help users optimize their income-to-expense ratio while building sustainable investment strategies to protect their savings against inflation.

## 🚀 Live Demo
You can view the live version of the project here: `https://nisanurozdemir.github.io/Budget-Tracker/`

## 🛠️ Key Features

- **Dynamic 50-30-20 Analysis:** Automatically categorizes user income and expenses into *Needs (50%)*, *Wants (30%)*, and *Savings/Investments (20%)* buckets, visualizing financial health instantly with neon progress bars.
- **Real-Time Currency Rates (Fetch API):** Programmed with asynchronous JavaScript to pull live exchange rates (USD/TRY, EUR/TRY) from open-source financial APIs upon every page load.
- **Mandatory Expense Tracking:** Locks essential costs like Rent, Utilities, and Groceries under a "Mandated Gider" status to feed the structural budget optimization logic.
- **Rule-Based AI Recommendation Engine:** Features twin dynamic panels ("AI Investment Assistant" and "AI Portfolio Suggestion") that adapt comments based on current budget percentages and real-time currency movements.
- **Modern & Responsive UI:** Designed with a sleek Dark & Neon Green cyber-fintech aesthetic, fully fluid and responsive across desktop and mobile devices via CSS Grid and Flexbox.

## 💻 Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties, Grid Layout, Flexbox)
- **JavaScript:** Vanilla JS (ES6+), Async/Await architecture, Fetch API
- **Fonts & Icons:** Google Fonts (Inter, Space Grotesk), FontAwesome v6
